## RA-05 生成再開 — 不合格（2026-11-28 10:47–10:53 JST）
- 条件: big.epub（3章・各2,377文字相当）を Edge TTS・文字数ごと（最大1000文字）で8ユニットに分割し一括生成。生成開始 10:47:18、Part 001/002 完了後の 10:48:29 に機内モードで通信を遮断した。
- 停止時: 進捗表示は「3 / 8」、完了ユニットのチェックが外れ、ボタンは専用の「続きから生成」に変わった（証跡 b31）。トークン再入力や購入の要求はなし。再開操作自体は仕様どおり存在する。
- 再開後: 通信復旧して「続きから生成」を押すと Part 004–008 が生成され、Part 001/002 のファイルは再生成されず保持された（サイズ・更新時刻不変）。最終表示は「MP3ファイルを生成しました。」（証跡 b32）。
- **問題**: 遮断時点で生成中だった Part 003 は 259,920 bytes のまま再開対象から外れ、切り捨てられたMP3が完成品として残った。実測再生時間は Part 003 = 43.3秒（992文字。正常なユニットは約170–186秒）。さらに再開側で生成した Part 006 も 260,640 bytes / 43.4秒と短く（976文字）、同様に途中で途切れた音声がエラー表示なく「完了」扱いになった。全ユニットの実測: 001=171.4s / 002=181.2s / 003=43.3s（欠落） / 004=172.5s / 005=186.5s / 006=43.4s（欠落） / 007=183.5s / 008=48.9s（255文字のため正常）。
- 期待結果「最初の未完了ユニットから続行でき、完成済みファイルと境界が維持される」に対し、生成途中のユニットが未完了として扱われず、欠落した音声が検出・再生成・警告のいずれもなく残るため不合格とする。
